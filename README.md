# iPhone Select — ЛР7, iPhone 18

Продовження готового сайту ЛР6 зі збереженням темного Burgundy-дизайну.
Запуск: локальний HTTP-сервер із цієї папки (наприклад python3 -m http.server 8077).
Відкривати http://localhost:8077, а не file://: ES-модулі потребують HTTP.

Каталог: iPhone 18 Pro і Pro Max, джерело https://www.apple.com/iphone-18-pro/specs/.
Ціни нових пристроїв не вказані. Trade-in — навчальна арифметика; кошик лише лічильник; підписка не надсилає даних.

360°: натиснути «Відкрити 360°», перетягувати мишею або горизонтально пальцем. Стрілки — обертання/нахил, +/− — масштаб, Home — скидання. Three.js 0.187.0 та модель завантажуються локально після натискання. Офіційна композиція містить два пристрої. Колір конфігуратора не змінює матеріал 3D. Внутрішні деталі не моделювалися. Для відео, карти, шрифтів та валютного віджета потрібен інтернет.

## Netlify
Існуючий сайт: https://iphone-select-horobets-lab6.netlify.app/
Оновлення лише після погодження користувача. Архів має index.html у корені. У кабінеті вибрати саме цей проєкт → Deploys → завантажити архів і перевірити Published та постійну адресу. Новий проєкт не створювати.

## Ресурси
Модель Apple USDZ перетворена OpenUSD: зведені шари USDA та збережені текстури. Це локальний пакет для USDLoader, не файл для Apple Quick Look. Джерела наведені у THIRD-PARTY.md. Hero відновлено з попередньої редакції: assets/images/hero_bg.webp. Решта старих медіа лишилася в резервних копіях.
Three.js MIT: vendor/three/LICENSE. Tailwind 4.3.3 зібрано в tailwind.css. Для зміни утиліт npm install та npm run build:css. Усі runtime-модулі вже включені, встановлення для публікації не потрібне.

## Редакція після перевірки звіту
Повернено попередній Hero, додано Послуги та Про нас. Trade-in: 35 моделей + Інша модель; суми умовні. Повторно перевірено 320–1440 px і статичні посилання. Lighthouse у evidence/iphone18-* належить попередній редакції. Публікація поточної редакції не виконана.
