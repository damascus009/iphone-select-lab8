## Результат і критична перевірка
- Наявні секції розподілено між п’ятьма адресами; модулі відокремлено за сторінками; усі внутрішні посилання перевірено.
- Swiper 12.2.0 підключено через CDN; кнопки, клавіатура та статична резервна сітка перевірені.
- Початковий аудит виявив помилки порядку заголовків, недоречну ARIA-роль слайдів і відсутній widget.css у маніфесті публікації. Заголовки впорядковано, слайди перетворено на div, CSS включено у маніфест.
- Заставка 3D розтягувалася через object-fit:fill; змінено на contain. YouTube завантажував сторонній код до дії користувача; додано явну кнопку завантаження.
- Спроба npm install у вже наявному дереві залежностей завершилася помилкою npm Arborist. Робочі залежності не видалялися; наявна збірка Tailwind успішна, Lighthouse встановлено окремо у тимчасовому каталозі.
- Підключення нового Vercel-проєкту безпосередньо до Git відхилене через відсутню інтеграцію. Використано дозволений файловий API, окрема стабільна адреса працює. Автодеплой не заявляється.
- Перші скриншоти після зміни viewport містили проміжний кадр браузера. Знімки повторено після завершення зміни розміру; наявність знімка сама по собі не вважалася доказом коректності.

Способи перевірки: 36 тестів правил форми; 84 структурні й інтеграційні браузерні перевірки; геометрія та 20 циклів 3D; WebGL failure/retry; CDN failure; реальні дії на опублікованому сайті; фінальні 10 аудитів Lighthouse; перегляд сторінок PDF. Точні результати в ../evidence/.
