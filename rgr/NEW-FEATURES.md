# РГР — поточне розширення

- Світла/темна тема: system preference, localStorage, синхронізація вкладок; fallback без storage.
- Каталог: `data.json`, fetch із таймаутом, перевірка структури, резервні HTML-картки.
- Open Graph / Twitter Card: 5 сторінок, canonical, JPEG 1200×630.
- Supabase: створено окремий free-проєкт, підключено до РГР; серверний вхід, HttpOnly-сесія та вихід перевірені на тимчасовому акаунті в реальному Supabase; тестовий акаунт видалено. Реєстрацію з доставкою листа ще не перевірено.
- Shopify: окремий SANDBOX створено, але не використовується сайтом. Власник повідомив про платний тариф після trial; платний тариф не активуємо. За рішенням власника платежі виключено зі scope: потрібне лише навчальне оформлення.
- Vercel Analytics: увімкнено на платформі; клієнтський код підготовлено. Не надсилає поля форм; очищає query/hash.
- CI/CD: workflow підготовлено; фактичний запуск і секрет VERCEL_TOKEN ще не перевірено.
- Історичні аудити у `evidence/lighthouse` стосуються попередньої версії від 15.11.2026.
